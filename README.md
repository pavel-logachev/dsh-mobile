# DSH Mobile

**Агент в [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) работает на вашем компьютере. DSH Mobile даёт доступ к нему с Android-телефона: открыть чат любого проекта, поставить задачу, следить за ответом в реальном времени и узнать уведомлением, что ответ готов.** Телефон привязывается по QR-коду и подключается к компьютеру по Wi‑Fi или через Tailscale. Облачного сервера у приложения нет: модели, инструменты, подписки и история остаются на компьютере.

## Что можно делать с телефона

**Работать с чатами.** Список проектов совпадает с боковой панелью DSH, включая порядок; новые проекты появляются без повторной привязки. Чаты можно искать, фильтровать по проекту и находить по группам «Сегодня», «Вчера», «На неделе». Чтобы начать новый чат, выберите проект и пресет и отправьте текстовую задачу.

**Следить за работой агента.** Ответ обновляется в реальном времени и отображается как Markdown: заголовки, списки, таблицы, блоки кода с копированием. В переписке остаются только ваши сообщения и ответы агента. Служебные события DSH — результаты сабагентов, фоновые задачи, обновления контекста — свёрнуты в строку «Действия агента», полный текст открывается по нажатию.

**Вмешаться, не дожидаясь конца.** Пока агент работает, можно дописать сообщение: оно встанет в очередь DSH и дойдёт до агента на следующем шаге. Кнопка «Стоп» вынесена отдельно и просит подтверждения.

**Получать уведомления.** По желанию включаются уведомления «Ответ готов» и «Агент ждёт вашего решения». В них только название проекта и чата, без текста ответа; на экране блокировки показывается только «Ответ готов». Уведомления можно выключить для отдельных проектов и чатов. Пока они включены, в шторке висит «DSH Mobile на связи». Сервисы Google не нужны.

**И мелочи, которые экономят время.** Поиск по переписке, меню копирования по долгому нажатию на сообщение, черновик для каждого чата. При обрыве сети во время отправки приложение сверяет статус задачи с компьютером, чтобы не запустить её дважды. Светлая и тёмная тема, русский и английский интерфейс, крупный шрифт.

## Как это устроено

```text
Android-приложение ──HTTPS (Wi‑Fi или Tailscale)──▶ плагин-компаньон внутри DSH ──▶ ваши проекты и агенты
                    └─ или через ваш собственный relay (опционально)
```

В DSH на компьютере устанавливается небольшой плагин-компаньон. Он открывает привязанным телефонам узкий API через защищённое соединение, а сам веб-интерфейс DSH наружу не публикуется. Телефон проверяет компьютер по сертификату, закреплённому в приглашении. У каждого телефона свой ключ и свои права, их можно отозвать.

Для привязки телефон сканирует одноразовый QR-код с экрана компьютера. Камера нужна только на время сканирования, код распознаётся без сети и без сервисов Google.

## Установка

Пошаговую инструкцию [docs/SETUP.md](docs/SETUP.md) можно отдать своему агенту DSH: он проверит версии, установит плагин и спросит согласия перед каждым важным действием. Коротко:

1. Проверьте требования: Windows, DeepSeek Harness `0.2.0-rc.2` или `0.2.1-alpha.1`, Node.js 24, OpenSSL 3, телефон на Android 8.0 или новее.
2. Скачайте из [Releases](https://github.com/pavel-logachev/dsh-mobile/releases/latest) подписанный APK, архив плагина `dsh-mobile-host-<версия>.zip` и их файлы `.sha256`. Сверьте контрольные суммы.
3. Установите плагин: запустите `install-host.ps1` из архива и укажите адрес компьютера — IP в домашней сети или имя в Tailscale. Скрипт сначала только готовит конфигурацию, а подключает плагин к DSH отдельным шагом `-Activate`, без перезапуска DSH.
4. Выберите права: чтение всех проектов и, если нужно, запуск задач. Правило брандмауэра Windows добавляется только для частной сети и только с вашего согласия.
5. Установите APK. Android попросит разрешить установку из этого источника.
6. Привяжите телефон: на компьютере `pair --qr`, в приложении «Сканировать QR-код», затем сверьте адрес и отпечаток сертификата и подтвердите.

Чтобы пользоваться приложением вне дома, поставьте [Tailscale](https://tailscale.com/) на компьютер и телефон и укажите при установке имя компьютера в tailnet. Это бесплатно, роутер настраивать не нужно. Если Tailscale не подходит, можно развернуть свой relay на VPS по инструкции [RELAY_DEPLOYMENT.md](docs/RELAY_DEPLOYMENT.md). Общего публичного relay проект не предоставляет.

Обновление с 0.4.0: APK ставится поверх, привязка сохраняется. Плагин обновляется через `install-host.ps1` из нового архива.

## Безопасность

- Плагин работает внутри DSH с теми же правами, что и сам DSH. Фильтр по проектам — не песочница: агент, запущенный с телефона, может всё то же, что и с компьютера. Право запускать задачи давайте только своим доверенным устройствам.
- Приглашение одноразовое и действует не дольше 15 минут. Передавайте его только напрямую: QR-кодом с экрана своего компьютера или файлом по доверенному каналу.
- Ключи телефона хранятся в Android Keystore и не попадают в резервные копии. Ключи компьютера лежат в профиле пользователя Windows с доступом только для владельца. Ключи провайдеров моделей на телефон не передаются.
- Relay, если вы его используете, пересылает зашифрованный трафик и не видит содержимого чатов, но видит IP-адреса, время и объём трафика.

Подробности — в [SECURITY.md](docs/SECURITY.md).

## Сборка из исходников

```powershell
cd host;  npm ci; npm ci --prefix ../relay; npm run check   # плагин-компаньон, Node 24; тестам нужен соседний relay
cd ..\android
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ../tools/android-build.ps1 -Tasks ':app:assembleDebug', ':app:testDebugUnitTest', ':app:lintDebug'"
```

Нужны JDK 21, Android SDK platform 36 и build-tools 36.0.0. Сборка релиза, подпись своим ключом и упаковка плагина описаны в [BUILD.md](docs/BUILD.md) и [ANDROID_RELEASE.md](docs/ANDROID_RELEASE.md).

## Ограничения

- Компьютер и DSH должны быть включены.
- Уведомления держатся на постоянном фоновом соединении. После перезагрузки телефона или принудительной остановки приложение нужно открыть, а агрессивная экономия батареи у некоторых производителей (OnePlus, Xiaomi и других) может задерживать доставку. На реальном телефоне уведомления пока проверены не были, только на эмуляторе. Push через UnifiedPush — в планах.
- Вложения, ответы на вопросы агента и подтверждения действий с телефона пока не поддерживаются: их нужно делать на компьютере.
- Одно приложение привязывается к одному компьютеру. В списке до 100 проектов.
- Поддерживаются только проверенные версии DSH. Плагин сверяет версию, указанную в его настройках, а не фактически установленную, поэтому после обновления DSH совместимость нужно проверить заново.

## English

DSH Mobile is an unofficial native Android client for DeepSeek Harness, developed independently of DeepSeek. Your DSH agent keeps running on your computer; the phone lets you open a chat in any registered project, send a text task, follow the live Markdown reply, add a follow-up while the agent is still working, or stop the run. Models, tools, subscriptions and history stay on your computer.

A companion plugin runs inside DSH and exposes a narrow API to paired phones over TLS; the DSH web UI itself is never exposed. The phone pins the computer's certificate from a one-use QR invitation, and scanning works offline without Google Play services. Connect over the same Wi‑Fi, over Tailscale or through your own relay. Each phone has its own key and revocable permissions. Project filtering is not a sandbox: an agent started from the phone can do anything it can do on the computer.

Supported DSH versions are `0.2.0-rc.2` and `0.2.1-alpha.1`; Android 8.0+ is required. You can hand the [setup runbook](docs/SETUP.md) to your DSH agent. Service events are folded into a collapsible "Agent activity" row. Optional notifications ("answer ready", "agent needs your decision") contain only project and chat names and use an opt-in foreground connection without Google services. Attachments and approvals from the phone are not supported yet.
