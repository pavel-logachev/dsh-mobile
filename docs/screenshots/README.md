These screenshots were captured by the Android native compositor using the opt-in multi-project fixture described in [Design](../DESIGN.md). Project names and messages are demo data. The fixture has no connection to a model, a real DSH conversation or a production host; it supplies the running indicator too.

The original portrait captures were 1080 × 2400. Public copies are downscaled with FFmpeg to 540 × 1200 for the documentation. They are not shipped as app assets and do not document physical-device acceptance. Original run metadata and receipts remain in ignored local artifacts.
